# TiLiA 0.7.4 keyboard shortcuts (2026-11-06)

On macOS, Ctrl is ⌘ (Command) and Alt is ⌥ (Option).

## Global

| Key | Action | Where to find it |
| --- | --- | --- |
| <kbd>Ctrl+N</kbd> | New | File → New |
| <kbd>Ctrl+O</kbd> | Open | File → Open |
| <kbd>Ctrl+S</kbd> | Save | File → Save |
| <kbd>Ctrl+Shift+S</kbd> | Save As | File → Save As |
| <kbd>Ctrl+J</kbd> | JSON | File → Export → JSON |
| <kbd>Ctrl+Shift+L</kbd> | Local | File → Load media → Local |
| <kbd>Ctrl+Z</kbd> | Undo | Edit → Undo |
| <kbd>Ctrl+Shift+Z</kbd> | Redo | Edit → Redo |
| <kbd>Ctrl+C</kbd> | Copy | Edit → Copy |
| <kbd>Ctrl+X</kbd> | Cut | Edit → Cut |
| <kbd>Ctrl+V</kbd> | Paste | Edit → Paste |
| <kbd>Ctrl+Shift+V</kbd> | Paste complete | Edit → Paste complete |
| <kbd>Ctrl++</kbd> | Zoom In | View → Zoom In |
| <kbd>Ctrl+-</kbd> | Zoom Out | View → Zoom Out |
| <kbd>Del</kbd> | Delete | anywhere |
| <kbd>Return</kbd> | Inspect | anywhere |
| <kbd>Space</kbd> | Play / Pause | Player toolbar |
| <kbd>Left</kbd> | Select the previous element | in a timeline |
| <kbd>Right</kbd> | Select the next element | in a timeline |
